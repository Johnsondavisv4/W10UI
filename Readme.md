# W10UI and UUP Converter — personal use

This project contains my personal modifications to the tools from **[abbodi1406/BatUtil](https://github.com/abbodi1406/BatUtil/)**.

Credit for the original scripts goes to **abbodi1406 and the project's contributors**. This repository keeps their tools with a few adjustments to my workflow for downloading, updating, and preparing Windows images.

## Tools

| File | Purpose |
| --- | --- |
| `W10UI/W10UI.cmd` | Integrates updates into a Windows image and creates an updated ISO. |
| `uup-converter-wimlib/convert-UUP.cmd` | Creates a Windows image or ISO from UUP files. |
| `uup-converter-wimlib/create_virtual_editions.cmd` | Creates virtual editions and keeps the selected editions. |
| `uup-converter-wimlib/To_IoT_LTSC.cmd` | A simplified variant for converting Enterprise LTSC to IoT Enterprise LTSC and applying the configured generic OEM key. |
| `C++/CBSReg.cpp` | Applies the registry operations generated by the scripts. |
| `C++/PSFDeltaExtractor.cpp` | Extracts PSF files and processes PA30/PA31 deltas using the appropriate DLL. |
| `PS1/Check.ps1` | Looks up the available build on UUP Dump. |
| `PS1/SO.ps1` | Downloads UUP system and application files. |
| `PS1/Updates.ps1` | Downloads updates for W10UI. |

## Personal modifications

- **Dynamic ISO naming**, including the Windows version, edition, revision, and language. For example: `Win11_26H2_IoTEnterpriseS_9818_es-mx.iso`.
- **C++ tools** that replace selected PowerShell blocks. If an executable is missing, the original block is used as a fallback.
- **Custom edition selection** through `AutoEditions`.
- **Detection of packages that retain their `.cat` without a standalone `.mum`**, while still requiring the manifest when its contents need to be read.

Third-party executables and libraries retain the credits of their respective authors.

## Usage

- Configure searches and downloads in `data.ini` at the project root. The helpers in `PS1/` require PowerShell 7 and resolve their paths independently of the current working directory.
- Review `W10UI/W10UI.ini` before updating an existing image.
- Review `uup-converter-wimlib/ConvertConfig.ini` before converting UUP files.
- Run image servicing scripts as administrator and work on a copy of the original source.

To rebuild the C++ tools, use `build_CBSReg.cmd` and `build_PSFDeltaExtractor.cmd` in the `C++` directory. They require the Visual Studio C++ build tools and produce x64 executables, which are copied to the `bin` directories of both projects.

See **[abbodi1406's original repository](https://github.com/abbodi1406/BatUtil/)** for the full instructions and requirements.
